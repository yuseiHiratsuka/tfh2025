# ゲームルール仕様書

## 1. ゲーム概要

### 1.1 基本コンセプト
複数人で**協力**して、指定された**開始文字**から**ゴール文字**まで絵しりとりで繋げるゲーム

### 1.2 ゲームの目的
- 開始文字から始まる絵を描き、最終的にゴール文字で終わる絵を出してゴールに到達する
- **全プレイヤーが協力して**ゴールを目指す
- **ゴール到達で全員クリア**（協力型ゲーム）
- ゲーム結果によりスコアが出るのでハイスコアを目指す

---

## 2. ゲームルール

### 2.1 基本ルール

#### 2.1.1 開始とゴール
- ゲーム開始時に**開始文字**と**ゴール文字**が決定される
- 例: 開始「り」→ ゴール「き」

#### 2.1.2 絵の提出
- プレイヤーは絵を描いてアップロードする
- **全プレイヤーが同時に提出できる（早押し方式）**
- AIが絵を認識して単語を判定する

#### 2.1.3 採用ルール
- **最初に正解した人の答えが採用される**
- 採用されると次のお題（最後の文字）が更新される
- 同時に複数の正解が来ても、最初に処理された1つだけが採用される

#### 2.1.4 しりとりルール
- 絵は現在のお題の文字から始まる必要がある
- 認識された単語の**最後の文字**が次のお題になる
- 同じ単語は2回使えない

#### 2.1.5 禁止ルール
- 「ん」で終わる単語は使用不可（ゴール文字が「ん」の場合を除く）
- 既に使用された単語は使用不可
- 1ターンでゴールに到達することは不可（最低3ターン必要）

#### 2.1.6 ゴール到達とクリア
- 認識された単語の最後の文字がゴール文字と一致したら**全員クリア**
- ゴールを出した人は記録される
- 全員で協力してゴールを目指す

## 3. ゲームフロー

### 3.1 ゲーム開始前
```
1. ルーム作成
   - 開始文字を設定（例: 「り」）
   - ゴール文字を設定（例: 「き」）

2. プレイヤー参加
   - 複数人が同じルームに参加

3. ゲーム開始
   - 最初のお題は「開始文字」
```

### 3.2 ゲーム中
```
現在のお題: 「り」から始まる絵を描いてください

↓ (プレイヤーが絵を提出)

P1: 「りす」の絵を送信 → AI認識中...
P2: 「りんご」の絵を送信 → AI認識中...
P3: 「らっぱ」の絵を送信 → AI認識中...

↓ (AI認識完了)

P2の「りんご」が最初に認識完了
→ ✅ 採用！次のお題は「ご」

P1の「りす」も正解だったが遅かった
→ ⚠️ 不採用（既に次のお題に移行済み）

P3の「らっぱ」は不正解
→ ❌ 不正解（「り」から始まっていない）

↓

現在のお題: 「ご」から始まる絵を描いてください

↓ (繰り返し)

...

↓

P7: 「まき」の絵を送信
→ AI認識: 「まき」（ま→き）
→ 最後の文字「き」= ゴール文字
→ 🎉 ゴール到達！全員クリア！
```

## 4. 判定ルール詳細

### 4.1 正解条件
以下の**全て**を満たす必要がある:

1. **開始文字が一致**
   - 認識された単語の最初の文字が、現在のお題と一致する
   - 例: お題「り」→「りんご」○、「ごりら」×

2. **最速で処理された**
   - 同じタイミングで複数の正解があっても、最初に処理された1つだけが採用
   - システム内部のシーケンス番号で判定

3. **「ん」禁止ルール**
   - 最後の文字が「ん」でない（ゴール文字が「ん」の場合を除く）
   - 例: お題「り」→「りんご」○、「りんご」の次が「ん」で終わる単語 ×

4. **重複禁止ルール**
   - 過去に使用された単語でない
   - 例: 既に「りんご」が使われている場合、再度「りんご」は使えない

5. **最低ターン数ルール**
   - 1ターン目でゴールに到達することは不可（最低3ターン必要）
   - 例: 開始「り」、ゴール「ご」の場合、1ターン目で「りんご」を出してゴールに到達することは不可

### 4.2 不正解パターン

#### パターン1: 開始文字不一致
```
お題: 「ご」から始まる絵
提出: 「りんご」
結果: ❌ 不正解
```

#### パターン2: 「ん」で終了
```
お題: 「り」から始まる絵
提出: 「りもん」(架空)
結果: ❌ 不正解
```

#### パターン3: 単語重複
```
過去に使用: りんご、ごりら、らっぱ
お題: 「り」から始まる絵
提出: 「りんご」
結果: ❌ 不正解
```

#### パターン4: タイミング遅延
```
お題: 「り」から始まる絵

P1: 「りんご」を送信 (10:00:00.100)
P2: 「りす」を送信 (10:00:00.200)

P1が先に処理完了 → ✅ 採用
P2も正解だが → ⚠️ 不採用（既に次のお題「ご」に進行済み）
```

#### パターン5: 1ターンでのゴール到達
```
開始: 「り」
ゴール: 「ご」
ターン数: 1ターン目

提出: 「りんご」（り→ご）
結果: ❌ 不正解
```

## 5. 文字処理ルール

### 5.1 ひらがな・カタカナの統一
- AIが認識した結果は全てひらがなに変換して判定
- 例: 「リンゴ」→「りんご」として処理

### 5.2 小文字の処理
- 拗音（ゃ、ゅ、ょ）や促音（っ）などの小文字が最後にある場合、大文字に変換
- 例:
  - 「きゃんでぃ」→ 最後は「ぃ」→「い」として次のお題
  - 「ねっと」→ 最後は「っ」→「つ」として次のお題

### 5.3 濁音・半濁音・拗音の処理
- 濁音（が、ざ、だ、ばなど）や半濁音（ぱ、ぴ、ぷ、ぺ、ぽ）、拗音（きゃ、しゅ、ちょなど）はそのまま認識される
- 濁音は清音に変換されない
- 拗音は構成文字に分解されない
- 例:
  - 「だ」は「た」とはならない
  - 「みゃ」は「や」ではなく「みゃ」として認識される
  - 「ぱんだ」の「だ」は「た」ではなく「だ」として処理される

### 5.4 長音（ー）の処理
- 長音記号は直前の母音として扱う
- 例: 「かれー」→「かれえ」→ 最後は「え」

---

## 6. ゲーム終了条件

### 6.1 クリア条件
- ゴール文字で終わる単語が採用された時点で**全員クリア**

### 6.2 制限時間
- 制限時間: 全体で2分
- 制限時間内にゴールに到達できない場合は失敗

### 6.3 失敗条件（オプション、実装次第）
- 制限時間切れ
- 最大ターン数到達
- 全プレイヤーがギブアップ

### 6.4 スコア計算方法（仮）
- 残り時間(秒数)x50点
- 絵が繋がった回数x1000点

## 7. UI表示要件

### 7.1 必須表示項目

#### ゲーム情報
- 現在のお題（文字）
- ゴール文字
- 現在のチェーン数（何個繋がったか）
- 参加プレイヤー一覧

#### 投稿一覧
各投稿には以下を表示:
- 投稿者名
- 投稿画像
- AI認識結果（認識中/完了/失敗）
- 採用状態（採用/不採用/不正解）

#### 採用履歴
- 採用された絵のみを順番に表示
- しりとりチェーンとして視覚化

### 7.2 状態別の視覚的フィードバック

#### 認識中
- ローディングインジケーター
- 「AI認識中...」テキスト

#### 採用
- 緑色の背景
- ✅ アイコン
- 「採用！」バッジ

#### 不採用（正解だが遅かった）
- オレンジ色の背景
- ⚠️ アイコン
- 「正解だが不採用」バッジ

#### 不正解
- 赤色の背景
- ❌ アイコン
- 不正解の理由を表示

#### ゴール到達（全員クリア）
- 全画面で祝福演出
- 🎉 アイコン
- 「みんなでクリア！」メッセージ
- ゴール到達者の名前
- クリア情報（ターン数、時間など）

## 8. ゲーム例

### 例1: 短いゲーム（全員クリア）
```
開始: 「り」
ゴール: 「ご」
参加者: P1, P2, P3

P1: りんご (り→ご) を送信
→ AI認識: 「りんご」
→ ✅ 採用
→ ゴール到達！全員クリア！

結果:
- クリアターン数: 1手
- ゴール到達者: P1
- 全員クリア！
```

### 例2: 標準的なゲーム（全員で協力）
```
開始: 「り」
ゴール: 「き」
参加者: P1, P2, P3, P4

ターン1: お題「り」
P1: りんご (り→ご) → ✅ 採用
P2: りす (り→す) → ⚠️ 不採用（既に次のお題へ）

ターン2: お題「ご」
P2: ごりら (ご→ら) → ✅ 採用

ターン3: お題「ら」
P3: らっぱ (ら→ぱ) → ✅ 採用

ターン4: お題「ぱ」
P1: ぱんだ (ぱ→だ) → ✅ 採用

ターン5: お題「だ」
P4: だるま (だ→ま) → ✅ 採用

ターン6: お題「ま」
P2: まき (ま→き) → ✅ 採用
→ ゴール到達！全員クリア！

結果:
- クリアターン数: 6手
- ゴール到達者: P2
- 全員クリア！
```

### 例3: 競争が発生するゲーム（協力しながら早押し）
```
開始: 「ね」
ゴール: 「こ」
参加者: P1, P2, P3

お題: 「ね」

P1: ねこ (ね→こ) 送信 10:00:00.100
P2: ねずみ (ね→み) 送信 10:00:00.150
P3: ねぎ (ね→ぎ) 送信 10:00:00.200

AI認識完了:
P1: 認識完了 10:00:01.300 → ✅ 採用（ゴール到達！）
P2: 認識完了 10:00:01.500 → ⚠️ 不採用（既にゴール）
P3: 認識完了 10:00:01.800 → ⚠️ 不採用（既にゴール）

結果:
- P1がゴールを決めた！
- でも全員クリア！みんなおめでとう！
```

### 例4: 不正解が出るゲーム
```
開始: 「さ」
ゴール: 「く」
参加者: P1, P2, P3

ターン1: お題「さ」
P1: さる (さ→る) → ✅ 採用

ターン2: お題「る」
P2: りんご (り→ご) → ❌ 不正解（「る」から始まっていない）
P3: るーる (る→る) → ❌ 不正解（既に「るーる」が使われている... わけではないが同じ文字に戻る）
P1: るびー (る→び) → ✅ 採用

ターン3: お題「び」
P2: びーる (び→る) → ✅ 採用

ターン4: お題「る」
P3: るすばん (る→ん) → ❌ 不正解（「ん」で終わる言葉は使えません）
P1: るーれっと (る→と) → ✅ 採用

... (省略)

最終的に全員クリア！
```
